# Sellsword Crown — 테스트 빌드

망국의 기사 지망생이 용병단을 키워, 악마와 계약한 제국에 맞서 용병왕이 되는 턴제 전술 게임 (개발 중).

## 플레이
**https://pbin528.github.io/sellsword_crown_test/** (PC 크롬·엣지 권장, 처음 불러오기에 조금 걸린다)

- 저장: 이 브라우저에 자동으로 남는다 (전투에서 돌아올 때마다). '저장' 탭에서 손 저장 3칸, **파일로 내보내기·불러오기** (다른 컴퓨터로 옮길 때)
- 브라우저 데이터를 지우면 저장도 지워진다. 오래 할 거면 가끔 파일로 내보내 두자

## 버그·의견 보내기
게임 중 아무 때나 **F8** → 종류를 고르고 적은 뒤 **보내기** → 새 창의 GitHub 이슈에서 **Submit**.
지금 상황(날짜·금·위치·전투 기록 등)이 자동으로 붙는다. 보낸 글은 이 저장소의 `reports/` 폴더에 글 파일로도 쌓인다.
GitHub 계정이 없으면 **글 복사**를 눌러 메신저로 보내 주면 된다.
